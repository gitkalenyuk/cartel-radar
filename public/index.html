Аналіз каналу

Вставте @handle, посилання або ID каналу. З ключем YouTube API — реальні цифри, без нього — експертний аналіз моделі.

Прев'ю-лаб (vision)

Vision-модель подивиться на реальні прев'ю найпопулярніших відео каналу або ніші й скаже, що працює, що слабко і які концепти зробити вам. Потрібен ключ YouTube Data API і модель із підтримкою зображень (Налаштування → маршрут «Прев'ю / vision»).

Gap-сканер ключових запитів

Три агенти паралельно розкладають тему на кластери довгого хвоста й оцінюють попит проти конкуренції.

Радар ніш

Шукає не гігантів, а свіжі прориви: молоді канали, які щойно пробилися в ніші. Саме там народжуються нові ніші з низькою конкуренцією. Дані беруться локально через yt-dlp — без ключа й без квоти.

Що шукаємо

Метод: канали з 5–75 тис. підписників (великі відсіюються — їхні перегляди це просто інерція підписників), відео не старші за вказаний термін, ключова метрика — перегляди ÷ підписники. Якщо канал ховає підписників, відео приймається лише за понад 50 000 переглядів.

Стан

Готово до запуску. Запуск триває від 20 секунд до кількох хвилин — залежно від кількості запитів.

Відео-лаб

Розбір упаковки конкретного відео: чому зайшло і як зробити краще.

Пайплайн ніш

Перетягуйте картки між колонками. Експорт звіту — у Markdown, CSV або JSON.

yt-dlp не знайдено — реальні дані не працюватимуть

yt-dlp — це безкоштовний локальний двигун, який тягне справжні цифри з YouTube без ключа й без квоти. Зазвичай він ставиться разом із застосунком. Якщо завантаження під час встановлення не вдалося (немає інтернету, антивірус, корпоративна мережа) — завантажте його зараз однією кнопкою.

Де саме застосунок шукав yt-dlp
Як отримати ключ: console.cloud.google.com → новий проєкт → APIs & Services → Library → «YouTube Data API v3» → Enable → Credentials → Create credentials → API key. Безкоштовно 10 000 юнітів на добу (один пошук ≈ 100 юнітів).

Оновлення

Застосунок зібрано з модулів — інтерфейс, логіка, сервер, довідка. Кожен можна оновити окремо, не перевстановлюючи програму: виправлення в інтерфейсі важить кілобайти замість 100 МБ інсталятора. Оновлення беруться з відкритого репозиторію, кожен файл звіряється з хешем, старі версії зберігаються в резервній копії.

Безпечно. Кожен файл звіряється з хешем із переліку в репозиторії. Якщо вміст не збігається — оновлення скасовується.
