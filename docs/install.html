Встановлення

Застосунок безкоштовний, працює локально й не потребує реєстрації. Потрібен лише Node.js 18+ — його ставлять один раз.

Спільний крок для обох систем

Встановіть Node.js LTS: nodejs.org → завантажити → «Далі-Далі-Готово». Нічого налаштовувати не треба.

Перевірка: відкрийте термінал (macOS) або командний рядок (Windows) і виконайте node -v. Має показати v18 або вище.

macOS

  1. Завантажте Cartel.Radar.1.1.0-arm64.dmg зі сторінки релізів.
  2. Відкрийте dmg і перетягніть Cartel Radar у папку Програми.
  3. Перший запуск: клацніть правою кнопкою на застосунку → Відкрити → у діалозі ще раз Відкрити.
  4. Якщо система блокує: Системні налаштування → Приватність і безпека → унизу «Все одно відкрити».

Застосунок відкриється у власному вікні — це не браузерна вкладка. Закривається звичайним ⌘Q; локальний сервер при цьому зупиняється сам.

Якщо ви клонували код із GitHub, замість архіву можна виконати ./install.sh — скрипт сам завантажить yt-dlp, збере застосунок і зробить ярлик на Робочому столі.

Windows

Портативна версія (нічого не встановлює)

  1. Завантажте Cartel-Radar-1.1.0-Windows-Portable.zip (полегшений, потрібен Node.js) або Cartel.Radar.Setup.1.1.0.exe (звичайний інсталятор).
  2. Розпакуйте у будь-яку папку, наприклад C:\CartelRadar. Саме розпакуйте — не запускайте зсередини архіву.
  3. Двічі клацніть Cartel Radar.bat. Відкриється браузер із застосунком.

Щоб видалити — просто видаліть папку. Нічого не залишається в системі.

Інсталятор

Файл Cartel.Radar.Setup.1.1.0.exe — звичайний інсталятор із меню «Пуск» і ярликом на робочому столі. Є також портативна Electron-збірка Cartel.Radar.1.1.0.exe, яка працює без Node.js.

Усі збірки збираються автоматично на GitHub Actions — файл .github/workflows/build.yml.

Де зберігаються ваші дані

СистемаТека
macOS~/Library/Application Support/CartelRadar/data
Windows%APPDATA%\CartelRadar\data
Linux~/.local/share/CartelRadar/data

Там лежать config.json (ключі та налаштування, доступ лише власнику), ніші, історія запусків і кеш зібраних даних YouTube. Дані не лежать усередині застосунку — тому оновлення не стирають ключі. Якщо ви встановлюєте нову версію, застосунок одноразово перенесе дані зі старих тек.

Оновлення

Завантажте новий архів і замініть застосунок. Дані залишаться на місці. yt-dlp можна оновити зсередини застосунку: Налаштування → Оновити yt-dlp.

Якщо щось не працює

СимптомЩо робити
«Застосунок пошкоджено» на macOSПравий клік → Відкрити. Або xattr -cr "/Applications/Cartel Radar.app" у терміналі.
Windows: «Node.js not found»Встановіть Node.js LTS і перезапустіть Cartel Radar.bat.
Порт 8787 зайнятийЗакрийте інше вікно Cartel Radar. Застосунок сам спробує наступні порти.
Антивірус свариться на yt-dlp.exeЦе відкритий інструмент з github.com/yt-dlp/yt-dlp. Додайте в довірені — без нього не буде безкоштовних даних YouTube.
